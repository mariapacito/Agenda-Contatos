## Tema do Projeto
Gerenciamento de Contatos

## Resumo do Problema
Muitas pessoas enfrentam dificuldades para organizar seus contatos pessoais e profissionais de forma eficiente. Informações importantes podem ficar espalhadas entre agendas físicas, aplicativos de mensagens e listas não organizadas, dificultando a localização rápida de contatos. Este projeto tem como objetivo desenvolver uma Agenda de Contatos digital que permita cadastrar, consultar, editar e excluir contatos de maneira simples e organizada.

## Requisitos Funcionais
- Adicionar contato;
- Editar contato;
- Excluir contato;
- Buscar contato por nome;
- Exibir lista de contatos.

## Requisitos Não Funcionais
- Pesquisa rápida;
- Interface responsiva;
- Facilidade de uso;
- Armazenamento seguro.

## Objetivo
Desenvolver uma aplicação web capaz de gerenciar contatos pessoais e profissionais, facilitando o armazenamento, a busca e a organização das informações dos usuários.
